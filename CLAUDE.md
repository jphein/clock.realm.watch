# clock.realm.watch

Static fantasy clock + temporal grounding hooks for Claude Code.

## Structure

- `index.html` — Fantasy clock UI (single file, inline CSS/JS)
- `version.json` — Realm-sigil version metadata (generated by build)
- `hooks/time-anchor.sh` — SessionStart hook, anchors each new session with current time (cheap, fires once)
- `hooks/time-awareness.sh` — UserPromptSubmit hook, injects current time only when the prompt regex-matches time-related phrasing
- Both hooks log skip/match events to `/tmp/time-awareness.log` (override with `$TIME_AWARENESS_LOG`)
- Symlinked into `~/.claude/hooks/` so the project files are the canonical source

## Build

Generate version.json:
```
~/Projects/realm-sigil/static/build.sh \
  --name clock.realm.watch \
  --description "Temporal grounding for the realm" \
  --realm stellar \
  --repo https://github.com/jphein/clock.realm.watch \
  --html index.html
```

## Time Awareness Rule

Before any claim about current time, time of day, elapsed time, time zones, or day of week, run `date +"%A %Y-%m-%d %H:%M:%S %Z"` first. Never estimate or infer the time from conversational cues.
